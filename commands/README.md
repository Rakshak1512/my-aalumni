# MyAlumni 2.0 — Commands & Terminal Operations

This directory contains reference documentation for executing terminal commands across the frontend, backend, testing, seeding, and deployment workflows.

> [!IMPORTANT]
> In accordance with project architectural specifications, this directory contains **documentation only**. No `.bat`, `.cmd`, `.ps1`, `.sh`, or other executable binary/script files are placed in this folder. All executable logic resides in `scripts/`, `backend/`, and `frontend/`.

## Document Contents

- [`COMMANDS.md`](./COMMANDS.md) — Comprehensive copyable command catalog organized by operating system (Windows PowerShell and macOS/Linux), working directory, and operational phase.
